session signal log
Fraud-detection signal demo. This is a prototype of the kind of signals a banking app might check during a logged-in session (impossible-travel, VPN mismatch, new-device checks). Nothing is collected until you explicitly consent below, and everything collected about you is shown back to you on this page — nothing is hidden in an admin-only view.

Before you continue, here's exactly what this demo will try to collect:

  • Your public IP and an approximate IP-based location (city-level, from a third-party lookup — not precise)
  • Precise GPS location — only if you grant your browser's location permission when prompted; you can deny this and the demo still works using IP-based location only
  • Browser/device info: browser, OS, screen resolution & viewport size, timezone, language, device memory & CPU core count (rough hardware class, not identity)

Timezone and language are compared against the IP-based country as an example of a VPN/location-mismatch heuristic — the kind of check a fraud system runs, shown here so you can see how it works, not to identify you personally.
